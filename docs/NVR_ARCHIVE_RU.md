# Архив видеорегистратора: выгрузка записей в Telegram

Бот забирает запись с видеорегистратора Hikvision (NVR/DVR) за нужное время и присылает её
в Telegram. Удобно, когда нужно быстро посмотреть или переслать фрагмент, а компьютера с
клиентом регистратора под рукой нет.

> Функция проверена автотестами, но на реальном регистраторе ещё не обкатана. Первый запуск
> делайте на одной камере и коротком отрезке (5 минут), см. раздел «Проверка».

## Как пользоваться

**Одной командой** — номер камеры (канала) на регистраторе и время:

```
/archive 26 13:30-14:00            сегодня
/archive 26 вчера 13:30-14:00
/archive 26 15.11 13:30-14:00      конкретная дата
/archive 26 23:50-00:10            через полночь
```

Время можно писать как `13:30-14:00`, `13.30 14.00` или `1330-1400`. Короткая форма
команды — `/arh`.

**Кнопками** — `/archive` или кнопка «🎞 Архив» под полем ввода: выбираете регистратор,
камеру из списка (названия берутся с регистратора), день, затем отправляете время сообщением.

Перед выгрузкой бот показывает, что именно будет выгружено, и предлагает два варианта:

- **▶️ Выгрузить** — основной поток, полное качество;
- **📉 Доп. поток** — уменьшенное качество, файл в несколько раз меньше. Работает, если
  регистратор пишет дополнительный поток.

Во время выгрузки сообщение обновляется (сколько уже скачано), есть кнопка «Отменить».
Видео приходит с подписью: регистратор, камера, время и кто запросил.

## Длинные записи

Длинный отрезок отправляется **несколькими видео подряд** — по 15 минут (настройка
`part_minutes`). Первая часть приходит, как только готова, не нужно ждать весь отрезок.

Почему не ZIP: видео уже сжато кодеком, архиватор уменьшает его на 1–2%, зато файл из ZIP
нельзя посмотреть прямо в Telegram. Ограничение Telegram — 2 ГБ на файл — ZIP не обходит,
а разбивка на части обходит. Если нужен меньший размер, используйте «Доп. поток».

## Ограничения

- **Скорость.** Регистратор обычно отдаёт архив со скоростью записи: 10 минут видео
  выгружаются около 10 минут.
- **Максимум за один запрос** — 2 часа (`max_duration_minutes`).
- **Одна выгрузка на регистратор одновременно**, остальные ждут в очереди.
- **Размер файла** — до 2 ГБ на одну часть. Если часть больше, бот предложит доп. поток
  или более короткий отрезок; можно уменьшить `part_minutes`.
- **H.265.** Такое видео на некоторых телефонах не проигрывается прямо в Telegram —
  откройте файл во внешнем плеере (VLC).
- **Время** — местное время регистратора. Часы регистратора и сервера с ботом (`TZ` в
  `.env`) должны совпадать.

## Настройка

Добавьте секцию `archive` в `configs/config.json` на верхнем уровне, рядом с `telegram` и
`camera_list` (готовый пример — `configs/archive-example.json`):

```json
"archive": {
  "enabled": true,
  "storage_path": "/data/archive",
  "max_duration_minutes": 120,
  "part_minutes": 15,
  "users": [],
  "nvrs": {
    "nvr_1": {
      "description": "Офис",
      "host": "http://192.168.1.10",
      "port": 80,
      "rtsp_port": 554,
      "auth": {
        "user": "archive-bot",
        "password": "пароль",
        "type": "digest"
      },
      "channels": {
        "26": "Склад, ворота"
      }
    }
  }
}
```

| Параметр | Что значит |
|---|---|
| `storage_path` | Папка для временных файлов. Файл удаляется сразу после отправки. |
| `max_duration_minutes` | Самый длинный отрезок за один запрос. |
| `part_minutes` | Длина одной части видео. |
| `users` | Кому разрешён архив (ID из Telegram). Пустой список — всем из `chat_users`. |
| `nvrs` | Регистраторы: ключ (`nvr_1`) — латиницей, `description` — название в боте. |
| `channels` | Необязательно: свои названия камер. Без этого названия берутся с регистратора. |

Обязательны только `nvrs` с `description`, `host` и `auth`; у остального есть значения по
умолчанию. Если камеры в этом боте не нужны, оставьте `"camera_list": {}`.

После правки конфига перезапустите бота:

```bash
docker compose up -d && docker compose restart hikvision-camera-bot
```

Команда `/archive 26 ...` работает с первым регистратором из списка; остальные выбираются
кнопками.

## Безопасность

1. **Согласуйте** использование бота с руководством и ИТ-службой: записи уходят на серверы
   Telegram.
2. **Отдельный пользователь на регистраторе** только с правом удалённого воспроизведения
   (Remote: Playback), без прав администратора. Пароль от `admin` в конфиг не кладите.
3. **Доступ** — только нужным людям: `chat_users` в секции `telegram`, а для архива можно
   сузить список через `archive.users`.
4. **Журнал.** Каждая выгрузка записывается в лог бота: кто, какая камера, какое время.
   Посмотреть: `docker compose logs hikvision-camera-bot | grep "Archive export requested"`.
5. Бот должен работать **в сети компании**, рядом с регистратором. Порты регистратора
   в интернет открывать не нужно.

## Проверка на своём регистраторе

1. Узнайте адрес регистратора и создайте на нём пользователя для бота.
2. Впишите секцию `archive`, перезапустите бота, отправьте `/archive`.
   - Список камер появился — связь и пароль в порядке.
   - «Не удалось получить список камер» — команда `/archive 1 ...` всё равно работает;
     причина будет в сообщении (сеть или пароль).
3. Запросите 5 минут: `/archive 1 12:00-12:05` и нажмите «Выгрузить».
4. Если пришло «запись не получена» — проверьте, что камера писала в это время, что у
   пользователя есть право воспроизведения и что открыт RTSP-порт (по умолчанию 554).
   Подробности: `docker compose logs --tail 100 hikvision-camera-bot`.

## Если что-то не работает

| Сообщение | Что проверить |
|---|---|
| Записей за это время нет | Номер камеры и время; пишет ли камера на регистратор. |
| Запись не получена | Право воспроизведения у пользователя, RTSP-порт, занятость регистратора. |
| Файл больше лимита Telegram | Выберите «Доп. поток» или уменьшите `part_minutes`. |
| Мало места на диске бота | Освободите место в `storage_path` (нужно от 3 ГБ). |
| Нет доступа к архиву | Ваш ID должен быть в `chat_users` (и в `archive.users`, если он задан). |
